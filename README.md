# Эволюция Глупого Кота (Web Clicker Game) 

Браузерная кликер-игра с механикой прокачки уровней, пассивным доходом и динамической экономикой улучшений.

---

### ⚙️ Реализованный функционал
* **Монетизация и SDK:** интеграция с Yandex Games SDK (просмотр Rewarded Ads за бонусы/множители).
* **Mobile-Friendly:** полная адаптивность под экраны смартфонов и планшетов, поддержка тач-событий.
* **Игровая экономика:** пассивный доход в секунду, расчет силы клика, динамический пересчет цен в магазине.
* **Система прогрессии:** шкала опыта, визуальные уровни эволюции персонажа и смена статусов кота.
* **Сохранение стейта:** синхронизация прогресса через `LocalStorage`.

---

### 🛠 Стек
* Vanilla JavaScript (DOM API, LocalStorage, Game Loop)
* HTML5 / CSS3
